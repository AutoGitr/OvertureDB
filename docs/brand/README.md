# Brand assets

These stacked logos are generated by [Overture's brand generator](https://github.com/AutoGitr/Overture/blob/main/frontend/scripts/generate-brand.ts)
from its shared Gallery mark and outlined Georgia wordmarks.

To refresh them, run `bun run generate:brand` in Overture's `frontend/` directory,
then copy `frontend/public/brand/overturedb-logo-stacked-*` into this directory.
Commit the refreshed SVG and PNG files together. No frontend tools are required
to use the checked-in assets here.

`-dark` variants belong on dark backgrounds; `-light` variants belong on light
backgrounds. Both have transparent backgrounds. The README selects the SVG
variant with `<picture>`; PNG exports are available for other uses.
